# Vr.exe

Low poly хоррор-паркур в браузере.

**Играть:** https://kafeevbogdan347-ui.github.io/Vr.exe/

## Сюжет

Белый человечек сидит дома и слушает музыку. Ему становится скучно, и он заказывает VR-шлем «ЭХО». Надев шлем, он встречает ИИ-помощника ЭХО. Тот просит пройти 5 стадий паркура, чтобы «настроить шлем».

С каждой стадией становится всё жутче: темнеет небо, искажается музыка, ЭХО начинает сбоить, а на столбах появляются фигуры, которые за тобой наблюдают. В конце человечек пытается снять шлем, но не может.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | бежать |
| Пробел | прыжок |
| Мышь | смотреть |
| Enter | пролистать реплику / пропустить вступление |
| E | действие |

## Запуск у себя

Игра написана на [Three.js](https://threejs.org/) и занимает один файл `index.html`. Её нужно открыть через любой локальный сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
