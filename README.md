# Vr.exe

Low poly хоррор-паркур в браузере.

**Играть:** https://kafeevbogdan347-ui.github.io/Vr.exe/

## Сюжет

Белый человечек сидит дома и слушает музыку. Ему становится скучно, и он заказывает VR-шлем «ЭХО». Надев шлем, он встречает ИИ-помощника ЭХО. Тот просит пройти 5 стадий паркура, чтобы «настроить шлем».

С каждой стадией становится всё жутче: темнеет небо, искажается музыка, ЭХО начинает сбоить, а на столбах появляются фигуры, которые за тобой наблюдают.

Если упасть, из темноты появляется **Квадратный** — белая угловатая фигура с золотым копьём. Его голова раскрывается почти целиком, как огромная пасть с зубами, и он съедает героя. Стадия начинается заново.

В конце шлем не снимается. Тогда приходит Квадратный, убивает ЭХО копьём и гонится за тобой по глючному коридору к выходу.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | бежать |
| Пробел | прыжок |
| Мышь | смотреть |
| Enter | пролистать реплику / пропустить вступление |
| E | действие |
| V | переключить русскую озвучку и формантный синтез голоса «ЭХО» |
| H | переключить оптический эффект визора VR-шлема «ЭХО» |

## Запуск у себя

Игра написана на [Three.js](https://threejs.org/) и занимает один файл `index.html`. Её нужно открыть через любой локальный сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
