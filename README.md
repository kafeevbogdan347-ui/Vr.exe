# Vr.exe

Low poly хоррор-игра в браузере.

Ночь, лес и хижина с заглохшим генератором. Найди 5 предохранителей и включи свет. После первого предохранителя в лесу просыпается кое-что ещё.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | идти |
| Shift | бежать |
| Мышь | смотреть |
| F | фонарик |
| E | взять / использовать |

Оно видит свет и слышит бег. Иногда лучше выключить фонарик и идти тихо.

## Запуск

Игра написана на [Three.js](https://threejs.org/) и занимает один файл `index.html`. Её нужно открыть через любой локальный сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
